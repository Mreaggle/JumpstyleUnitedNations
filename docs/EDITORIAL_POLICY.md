# Editorial and Evidence Policy

## Purpose

JUN distinguishes preserved memory from verified history. Both are valuable, but they must not be presented with the same level of certainty.

## Evidence statuses

| Status | Meaning | Timeline use |
| --- | --- | --- |
| `verified` | Official record or multiple independent reliable sources | Ready |
| `supported` | Strong contemporary source or original public media metadata | Ready with citation |
| `community-lead` | First-person or community lead awaiting public corroboration | Research queue only |
| `unverified` | Claim lacks enough evidence or contains unresolved conflict | Do not promote |
| `legacy-template` | Scaffold text inherited from the original repository | Never treat as evidence |

## Date policy

Store these dates independently whenever available:

- `event_date`: when the meeting, battle, release or other event happened.
- `upload_date`: when public media was published.
- `archive_date`: when a page was captured by an archive.
- `access_date`: when a researcher checked the source.

Priority is event date from the source title or description, then an explicit date from a contemporary page. If no event date survives, an upload date may be used only with a visible fallback label. Archive dates do not become event dates without additional evidence.

## Source handling

- Link directly to the strongest public source.
- Add an archived URL for fragile or deleted pages.
- Preserve source language and original names.
- Summarize; do not copy entire articles, forum posts or descriptions.
- Do not use search snippets as final evidence when the underlying page can be checked.
- Do not use private chats as citations.

## Corrections and disagreement

Additions to the global timeline should not delete existing history. When sources conflict, retain the competing claim in the research queue, explain the conflict and request review. A destructive correction requires maintainer approval and a rationale in the pull request.

## Key Figures

Key Figures Worldwide is a community-curated influence index, not an objective all-time ranking. Entries should explain influence, era, country and evidence. Popularity alone is not sufficient, and absence from the list does not imply lack of importance.
